# Corbit Mono

A futuristic open-source monospace developer font for Flutter.

## Installation

Add `corbit_mono` to your `pubspec.yaml`:

```yaml
dependencies:
  corbit_mono: ^1.0.0
```

Or run:

```bash
flutter pub add corbit_mono
```

## Usage

```dart
import 'package:corbit_mono/corbit_mono.dart';

// ...
Text(
  'print("Hello Corbit");',
  style: CorbitMono.textStyle(fontSize: 16),
)
// ...
```

## Features

- High legibility for code.
- Futuristic, tech-inspired design.
- Supports ligatures (like `=>`, `!=`).
